# Play Store listing assets

| Play Console field | File | Spec |
|---|---|---|
| Short description (max 80 chars) | `short_description.txt` | 70 chars |
| Full description (max 4000 chars) | `full_description.txt` | |
| App icon | `graphics/app_icon_512.png` | PNG, 512×512 |
| Feature graphic | `graphics/feature_graphic_1024x500.png` | PNG, 1024×500 |
| Phone screenshots (2–8) | `screenshots/phone/` | 8 × PNG, 1080×1920 (9:16) |
| 7-inch tablet screenshots | `screenshots/tablet-7in/` | 8 × PNG, 1080×1920 (9:16) |
| 10-inch tablet screenshots | `screenshots/tablet-10in/` | 8 × PNG, 1620×2880 (9:16) |
| Privacy policy | `privacy_policy.md` | publish on Google Sites |

## Notes
- Screenshots were captured from the app's web build in headless Chrome, using sample documents (invoice, receipt, letter, agreement, notes), not real data. The live camera screen is not included; add a real-device screenshot of it if you want one.
- Tablet screenshots show the same app at tablet widths, not a separate tablet layout.
- Before uploading, replace the screenshots with ones taken on a real device if you prefer.
